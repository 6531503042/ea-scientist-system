System Requirements จาก TOR: โครงการพัฒนาระบบสถาปัตยกรรมองค์กร (EA) และระบบยืนยันตัวตน
เอกสารฉบับนี้รวบรวมเฉพาะข้อกำหนดทางเทคนิค (Functional & Non-Functional Requirements) สำหรับการพัฒนาระบบตาม TOR ของกรมวิทยาศาสตร์บริการ เพื่อใช้เป็นแนวทางสำหรับทีมพัฒนา (Development Team)

1. ระบบสถาปัตยกรรมองค์กร (Enterprise Architecture Tools)
   อ้างอิง: ภาคผนวก ง
   หมวดหมู่
   ข้อกำหนดทางเทคนิค (Requirement)
   มาตรฐาน (Standards)
   รองรับการจัดเก็บและบริหารจัดการข้อมูลตามกรอบ TOGAF หรือเทียบเท่า ครอบคลุม 5 ด้าน (Business, Data, Application, Technology, Security)
   การจัดการข้อมูล (Data Management)
   สามารถบันทึกและจัดเก็บ EA Artefacts (เช่น รายการระบบงาน, รายการข้อมูล)
   สามารถสร้างและแก้ไขความสัมพันธ์ (Relationship) ระหว่างองค์ประกอบต่างๆ ได้
   รองรับการจัดการเวอร์ชัน (Version Control) ของข้อมูลแต่ละรายการ
   รองรับการนำเข้า/ส่งออกข้อมูล (Import/Export) ในรูปแบบ CSV หรือ Microsoft Excel
   การแสดงผล (Visualization)
   แสดงผลความเชื่อมโยงในรูปแบบแผนผัง (Interactive Graph หรือ Tree View)
   มี Dashboard สำหรับผู้บริหารเพื่อแสดงภาพรวมในรูปแบบที่เข้าใจง่าย
   มีระบบสืบค้นข้อมูลแบบ Full-text Search และการกรองข้อมูล (Filter)
   การเข้าถึงและสิทธิ์
   รองรับผู้ใช้งานพร้อมกันไม่น้อยกว่า 20 ราย
   มีระบบจัดการสิทธิ์ผู้ใช้งาน (RBAC) อย่างน้อย 3 ระดับ: Admin, Architect, Viewer
   รองรับการเชื่อมต่อกับระบบยืนยันตัวตนแบบรวมศูนย์ (เช่น LDAP หรือ Active Directory)

2. ระบบยืนยันตัวตนและจัดการการเข้าถึง (WiFi Authenticator)
   อ้างอิง: ภาคผนวก จ
   หมวดหมู่
   ข้อกำหนดทางเทคนิค (Requirement)
   ขีดความสามารถ (Capacity)
   รองรับการใช้งานพร้อมกันไม่น้อยกว่า 3,000 อุปกรณ์ (Concurrent Users)
   การยืนยันตัวตน (Authentication)
   รองรับการลงทะเบียนด้วยตนเอง (Self-register), ผ่าน Social Media (Facebook, LINE), SMS
   รองรับการอ่านข้อมูลจากบัตรประจำตัวประชาชน (Smart Card Reader)
   เชื่อมต่อกับฐานข้อมูลผู้ใช้งานเดิม (Active Directory / LDAP) ได้
   กฎหมายและความปลอดภัย
   เก็บข้อมูลจราจรคอมพิวเตอร์ (Log) ตาม พ.ร.บ. คอมพิวเตอร์ฯ ไม่น้อยกว่า 120 วัน
   แยกบทบาทผู้ดูแลระบบ (Admin) และผู้ดูแลข้อมูลจราจร (Log Admin) ออกจากกัน
   เข้ารหัสข้อมูลส่วนบุคคลที่มีความละเอียดอ่อน (Data Encryption)
   รองรับโปรโตคอลความปลอดภัย SSL/TLS Version 1.2 ขึ้นไป
   การจัดการเครือข่าย
   กำหนดความเร็ว (Bandwidth Control) และระยะเวลาการใช้งาน (Session Timeout) ได้
   มีหน้า Login แบบ Responsive Design (รองรับ Mobile/Tablet) อย่างน้อย 2 ภาษา
   มีระบบแจ้งเตือนผ่านอีเมล (Email Notification) หากระบบเกิดความขัดข้อง

3. โครงสร้างพื้นฐาน (Infrastructure & Non-Functional)
   อ้างอิง: ภาคผนวก ค และข้อกำหนดทั่วไป
   Server Specification: CPU 10-core (2.2GHz), RAM 16GB ECC, SSD 480GB x2 (RAID Support), Redundant Power Supply
   Availability: ระบบต้องทำงานได้ต่อเนื่อง 24x7 และมีระบบสำรอง/กู้คืนข้อมูล (Backup & Restore)
   Maintenance: รับประกันและดูแลระบบเป็นเวลา 3 ปี นับจากวันส่งมอบงานงวดสุดท้าย

หมายเหตุ: รายละเอียดนี้เป็นการสรุปเพื่อใช้ในการพัฒนาโปรแกรม โปรดอ้างอิงเอกสาร TOR ฉบับเต็มเพื่อตรวจสอบรายละเอียดเชิงลึกและเกณฑ์การตรวจรับงาน
